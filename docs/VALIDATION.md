# 验证范围与记录

公开版来源于课题组试用版的已验收代码，版本 0.3.0 新增通用待填写 API 模板、首次使用提示、网页/CLI Vendi 演示和开源说明。0.3.1 修正一项 Vendi 跨机器数值测试：q=0 在本机为 2，在 GitHub Windows 为 3.0000000000000004，均来自极小特征值的舍入。测试现在核对本机原函数的实际正特征值计数，同时仍要求 MCP 明确拒绝 q=0。没有修改原科学代码、历史数值或运行时适配器；原 0.3.0 包和失败记录均保留。

## 本次公开版源码检查

- 68 项测试及 6 项子测试通过，未跳过测试。覆盖个人论文库隔离、缓存、凭据不回显、DPAPI、服务切换、引用展示、错误分类、静态扫描、MCP 原函数绑定及本地模型拦截。
- 新 CLI Vendi 演示的 5 项实际 stdio 调用通过：两项工具、四次成功数值比较和一次 q=0 预期拒绝。原始结果在测试个人目录保留。
- 最终发行 ZIP 的新目录安装、CLI、网页与演示验收记录随 Release 提供。读者可核对该记录中的 ZIP SHA-256；源代码测试通过不替代解压安装验收。
- GitHub CI 在 Windows / Python 3.11 上复跑离线软件测试、Vendi 原函数测试及真实 stdio 调用，不使用论文、API 密钥或模型。

本轮发行整理没有新增付费远程模型调用，也没有调用本地模型或 GPU。软件测试中的问答接口使用假远程响应，PDF 使用明确标记的合成内容。

## 此前真实论文问答审查摘要

此前试用版使用用户配置的远程 API，选取 Attention、LoRA、QLoRA、HumanEval 和 DPO 的固定公开论文版本。22 项审核记录中，15 项回答通过独立原文审查，6 项为缺证据拒答，1 项为远程服务超时。超时没有作为准确回答或缺证据拒答计分。

审核核对引用对应的 PDF 哈希、原文、页码与定位，并检查数量措辞、逻辑方向、成立条件和跨论文引用覆盖。该固定题集的审查不能证明所有后续问题都准确。原始论文、API 响应及个人工作区留在本机，本仓库仅发布这段摘要；本次开源整理没有重新声称运行该远程题集。

## Vendi 独立科学验证

内置示例来自已经开源的 [vendi-score-mcp](https://github.com/Liuenzecs/vendi-score-mcp)：81 项独立测试通过；真实 stdio 原始验证包含 33 次成功调用和 38 次预期错误；独立解压包的 18 项正式 MCP 验收及额外数值比较通过，最大差异为 0。

完整的数值参考、来源哈希及路径脱敏报告见 [examples/vendi/mcp/reports](../examples/vendi/mcp/reports)。路径替换仅影响环境元数据，原始数值保留。q=0 的原实现异常结果也保留，并由 MCP 明确拒绝。

本仓库验证两个数值核心，不声称训练、数据集实验或全篇论文复现。代码保护不是通用沙箱。

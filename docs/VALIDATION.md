# 验证范围与结果

Paper2Agent 1.1.0 的验证包含固定论文库问答对照、研究代码科学计算对照、软件回归和发行安装验收。机器可读统计与源文件校验值见 [study-results.json](study-results.json)。

## 论文问答对照

对照对象为 `paper-qa 2026.8.12` 原版 `Docs.aquery`，双方使用相同 PDF 字节、问题、远程问答与嵌入服务、回答长度设置。分别测试统一文本切分与 PaperQA 原生解析；不包含上游自主文献搜索代理。

本轮包含 51 篇公开论文、519 道题，每种解析条件各生成双方 1,038 个原始答案，共 2,076 个答案。论文在作答前划分开发集与独立评估集，锁定题目、源码和统计方法。主要统计使用独立评估集的 39 篇论文、383 道单论文题；跨论文题单独报告。覆盖计算机与 AI、统计与数值计算、物理与工程、经济与能源规划、环境科学、生物科学六类主题。

严格合格要求回答问题所需事实完整、实际新增主张有证据且引用对应、正确划分已知与缺失信息。执行或证据审核失败仍计入分母，不视为成功拒答。

| 指标 | 统一切分 PaperQA | 统一切分 Paper2Agent | 原生解析 PaperQA | 原生解析 Paper2Agent |
| --- | ---: | ---: | ---: | ---: |
| 严格合格答案 | 354/383（92.4%） | 371/383（96.9%） | 366/383（95.6%） | 372/383（97.1%） |
| 缺证据问题正确拒答 | 76/78（97.4%） | 77/78（98.7%） | 77/78（98.7%） | 77/78（98.7%） |
| 可回答题全局误拒答 | 3/305（1.0%） | 0/305（0%） | 0/305（0%） | 0/305（0%） |
| 事实主张引用准确率 | 1636/1664（98.32%） | 1243/1245（99.84%） | 1562/1576（99.11%） | 1233/1235（99.84%） |
| 执行或审核失败 | 0/383 | 9/383 | 0/383 | 8/383 |

统一切分下，严格合格率提高 **4.44 个百分点**，相对错误减少 **58.6%**；按论文聚类的配对 bootstrap 95% 置信区间为 **+1.57 至 +7.27 个百分点**。原生解析下，提高 **1.57 个百分点**，相对错误减少 **35.3%**；置信区间为 **−1.32 至 +4.39 个百分点**，尚不能确认该条件下统计显著领先。缺证据拒答在原生解析条件下持平。

### 方法与边界

- 本轮以实际问题为准，未被问及的答案卡条目不要求额外作答；所有实际附加主张仍须有证据。各轮规则差异保留于统计记录，不跨轮合并显著性。
- 远程匿名评分与生成分开。主要统计中的分歧、全部歧义或评分错误，以及随机抽取的 10% 一致结果查阅完整原文复核。统一切分最终复核 99 对，原生解析复核 93 对。复核者为 Codex，未复核的一致答案保留可能有误的远程评分；这不等同于外部领域专家盲评，答案风格也可能暴露方法身份。
- 原图核查发现 Molass Figure 2 标有三个组分，题目卡却将组分数列为缺失。保留原题与原答案，对两种解析均将遗漏已知组分数的拒答判为不合格。统一切分的匹配核查是在原生解析核查后追加；预定复核统计亦完整保留，没有删题或重新作答。
- 所有原始响应、评分错误、审核失败与复核记录保留。一个未被引用的同文档重复片段别名仅在评分输入中做机械去重；引用锚点的字面修正不改变科学判定。
- 48 篇主要为较短的英文 JOSS 软件论文，另有三篇较长的 arXiv 论文，问题为英文。主题分类存在交叉，不能据此推断全部学术体裁、语言、扫描版 PDF 或专业高风险应用的表现。
- 使用火山引擎 `openai/ark-code-latest`；服务返回自动模型别名，底层模型身份与货币费用无法确认。嵌入为 `openai/doubao-embedding-vision`，2048 维；问答处理使用文本。统一切分预热共同嵌入缓存，原生解析上游片段未预热，因此耗时并非严格冷启动基准。
- Paper2Agent 使用额外检索与核验，token 与延迟成本更高，此对照不控制总计算量。引用准确率的主张分母因回答长度与内容不同而不同，并以有评分主张为条件；失败率另列，避免将屏蔽输出误读为准确回答。
- 文本提取可能丢失公式排版、上标或图中数值。复核时查看原图不代表产品问答已具备图像解析能力。

## 研究代码与 MCP 对照

固定源码直接执行与真实 stdio MCP 调用使用相同输入，比较数组全部元素、置信区间、缺失值位置，以及 R 原生对象的类、属性、标识符与文件字节。

| 来源 | 验证对象 | 独立解压验收 |
| --- | --- | --- |
| [SALib](https://github.com/SALib/SALib) | Sobol 采样与敏感性分析，提交 `748cf169e82227bcc56dcfc961fcfb03a1e0df45` | 12 次正向、6 次错误输入调用，完整数值对照通过 |
| [effectsize](https://easystats.github.io/effectsize/) | 1.0.3 的 `cohens_d`、`glass_delta` | 独立 Python 与 R 依赖恢复，37 次调用、13 组完整原生对象/CSV/传输结果对照通过 |
| 通用原生命令适配 | 审核的 R 入口与 SALib 原始 CLI | 最终修订 94 次调用，48 组 R 对象、10 组 CLI 完整数值对照通过；独立回归 66 项通过 |

通用 Python 接口支持具有明确参数类型的函数，并通过绑定源码校验值的接口定义处理 NumPy 数组、DataFrame、文件路径、异步和类方法。R 与 CLI 使用固定参数列表、严格 JSON 输入和审核契约。超时终止只作用于本次调用创建的子进程；运行隔离不构成操作系统安全沙箱。

这些结果验证所选函数及输入范围。运行成功、接口校验通过与研究结论成立属于不同层次；任意仓库的完整实验复现仍需审核源码、依赖与统计假设。

## 软件与发行验证

最终问答实现的软件回归为 **149 项通过、9 项跳过、6 个子测试通过**。独立原生命令验收另行启用 R 环境并通过其全部 66 项回归；两组范围不同，不合并为无跳过的整体测试结果。

回归覆盖论文库隔离、PDF 导入、API 配置与凭据保护、引用定位、回答状态、嵌入缓存、逐主张核验、代码扫描、源码绑定、输入校验、超时处理和原始结果存储。离线测试使用合成文件、夹具与模拟响应；真实远程问答和科学计算独立记录。

发行验收检查同一归档的独立目录安装、锁定依赖、网页与 CLI 操作、真实 MCP 调用和文件校验值。发行资产包含包清单、SHA256 与验收记录。公开包不包含用户论文库或 API 凭据。

[GitHub Actions](https://github.com/Liuenzecs/paper2agent-workbench/actions/workflows/verify.yml) 提供提交级状态；[最新发行版](https://github.com/Liuenzecs/paper2agent-workbench/releases/latest) 提供安装包。

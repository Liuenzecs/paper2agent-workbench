# 验证记录

网页和 CLI 使用同一套论文库、远程 API 配置与 MCP 生成逻辑。发行包不包含开发参考代码、测试数据、论文或密钥，也不提供示例入口。

源码离线回归覆盖论文库隔离、凭据保护、引用定位、拒答和服务错误分类、代码扫描、原函数绑定、严格输入校验与结果隔离。科学代码参考测试仅在开发仓库中运行。

本次版本删除展示性文案、示例命令和示例 HTTP 入口，保留必要的状态与错误信息。问答核心及 MCP 算法绑定未改动。验收包括新目录安装、浏览器三个页面、实际 MCP 成功与拒绝调用、CLI、打包内容和 GitHub CI，具体证据随 Release 提供。

本次没有调用本地模型、GPU 或远程模型 API，论文问答接口的离线软件测试使用假响应，不代表新的真实论文回答审查。已有真实远程问答审查结果保存在本机，不能据固定题集声称任意新问题准确。只运行可信且已审阅的研究代码。
